# Cat-Litter-Box
A custom cat litter box that is highly customizable and accessible.

# Electronic-Components
- Raspberry pi 5
- Adafruit Motor Hat
- DC WGM5840-31ZY 12V 7RPM Motor
- 5V & 12V Power Supply
- Female Power Adapter
- 20 mm OD Bushings
- Gearbox with 1:1 gear ratio
- 5mm key for the Gearbox
- Love joy connection (15 mm OD, 8 mm OD)

# Usage
Listed are the STL files that need to be 3D Printed any litter is fine as long as it is between 7-10 Lbs or 3-4.5 Kgs.
1. First assemble the electronic components (https://www.youtube.com/watch?v=ea6tSppgZlY&t=3s) //note that this is for the Raspberry pi 4; however, the steps are practically the same
2. Configure the raspberry pi app (https://www.youtube.com/watch?v=WBLpaS86Z9c&t=156s)
3. Code the raspberry pi (https://www.youtube.com/watch?v=HITf-_koVgs&t=187s) //basic tutorial (code template is in another file)

# Cat-Litter-Box
A custom cat litter box that is highly customizable and accessible.

# Electronic-Components
- Raspberry pi 5
- Adafruit Motor Hat
- DC WGM5840-31ZY 12V 7RPM Motor (buy the ones with a bracket mount)

# Usage
Listed are the STL files that need to be 3D Printed any litter is fine as long as it is between 7-10 Lbs or 3-4.5 Kgs.
